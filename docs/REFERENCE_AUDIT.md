# 实现口径记录

更新日期：2026-10-29。

## 数据格式

每个字段一个 pickle 宽表，行索引为 YYYYMMDD 日期字符串，列为稳定证券 ID。股票字段共用同一交易日历、证券集合和列顺序，数值通常写成 float32，行业保存分类字符串。金额和市值使用美元，成交量使用股。

## 模型

固定参数为深度 7、学习率 .03、500 树、subsample=1、colsample_bytree=1、gamma=.1、lambda=1、hist/cuda、max_bin=256。

训练从 2015 年开始，2023–2025 每半年重训一次。原生 XGBoost 通过 num_boost_round=500 实现固定树数，不进行交叉验证集成或早停；None 缺失配置映射为 np.nan。

## 标签

默认标签是 VWAP T+1 到 T+11 的复合收益，经信号日 log 市值和行业 WLS 中性化后截面标准化。WLS 目标权重为 sqrt(cap)。另可显式选择未来十日收盘收益求和的 close_sum 模式，标签元数据记录实际模式与结束日期。

缺失的未来收益窗口不填零，不使用未来交易状态决定信号日股票池。

## 风格模型与归因

沿用参考实现的价格描述子、预处理、风格合成、正交化、联合 WLS 与收益归因核心。细项和合成风格均使用 MAD 处理、市值加权均值及等权总体标准差；正交化权重为 sqrt(cap)。价格与财务细项及美股接口见 [BARRA_PORT.md](BARRA_PORT.md)。

一次构建股票暴露、因子收益和特异收益模型库，持仓分析直接复用。信号 T 的暴露解释策略相同的 VWAP T+1 到 T+2 收益；原归因函数通过日期视图适配使用，不拿 T+1 收盘暴露解释入场后收益。

组合、基准和主动权重分别计算暴露与贡献，成本单列，Carino 多期链接。原报告结构保留风格、行业和单位收益拆解，并加入累计收益、回撤与最大回撤。不把简单历史协方差估计作为默认已完成的风险归因。

## 递归爆搜

默认使用原因子包的递归表达式生成器与算子库，保留层级展开、量纲类别和跨层限制。数据、评价器、进程初始化与日志按当前项目接口适配；源码哈希和一致性验证见 [ENGINE_PORT.md](ENGINE_PORT.md)。
