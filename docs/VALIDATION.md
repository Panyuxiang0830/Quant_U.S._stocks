## 实际合成数据流程

运行 `usq demo --output <独立目录> --full`：

- 60 个虚构证券，2014–2026 年初工作日人工价格和基本面；不是实际美股日历。
- 数据审计、VWAP 和中性标签生成。
- 递归生成并评估 16 个候选、保留 4 个，完成训练/验证简单评估、验证复杂评估和相关计算。
- 复杂因子报告实际复用固定模型库完成风格收益归因。
- 六个半年度 XGBoost 原生模型，全部 500 树，明确 device=cpu。
- 每期 max_train_label_end 严格早于 period_start，训练起点均为 2015。
- 781 个工作日收益观测、50 个 score 分组、交易成本、基准、净值和回撤。
- 十个参考风格、组合/基准/主动暴露和收益归因、Carino 链接；模型库复用、独立持仓绝对收益归因。
- 每日组合归因最大误差约 5.20e-18；主动累计链接最大误差约 2.78e-15。
- 全候选 IS/VAL RankIC 导出和 20 次条件 Bootstrap 演示运行通过。

默认 `select` 的通过/淘汰与固定方向由测试验证；人工流程为保证覆盖六次模型训练，单独使用明确标记的演示清单，没有把“通过验证筛选”作为人工样本结论。
